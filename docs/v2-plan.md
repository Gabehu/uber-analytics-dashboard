# V2 Plan

V2 will rebuild the Streamlit prototype as a full web app with a separate frontend and backend.

## Goal

Recreate V1.1 functionality with better structure, routing, and UI.

## Planned pages

- Dashboard
- Add Entry
- Entry Detail
- Edit Entry
- Analytics

## Backend

- FastAPI
- SQLite
- CRUD endpoints for workday entries
- Weekly summary endpoints

## Frontend

- React + Vite
- Recharts for charts
- CSS or Tailwind for styling later

## Initial V2 milestone

Create the backend API and confirm entries can be added, listed, edited, and deleted through API routes.
